# HomeRouteApp

Android-приложение для автоматического уведомления при выезде из дома.

## Сценарий

- Сохраняет текущую точку как «Дом».
- Отслеживает геозону вокруг дома.
- При выходе из геозоны показывает уведомление.
- Нажатие на уведомление открывает Яндекс Карты.
- Маршрут строится от текущего местоположения до KazanMall.
- После возвращения домой приложение снова готово к следующему выезду.
- Геозона восстанавливается после перезагрузки телефона.

## Пункт назначения

KazanMall, Казань, улица Павлюхина, 91.

## Разрешения

Нужны точная геолокация, разрешение на работу геолокации в фоне и уведомления.

## Сборка

Проект рассчитан на Android Studio с JDK 17. GitHub Actions автоматически собирает debug APK при push в main.

APK: app/build/outputs/apk/debug/app-debug.apk
